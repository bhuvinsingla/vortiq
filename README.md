# Vortiq website

React + Vite + TypeScript + Tailwind CSS v4.

## Run
    npm install
    npm run dev

## Structure
- `src/data/content.ts`     all copy and sample projects (edit this first)
- `src/types/`              shared TypeScript types
- `src/components/layout`   Navbar, Footer
- `src/components/sections` one file per page section
- `src/components/ui`       reusable pieces (Button, Section, Reveal, Icon)
- `src/hooks`               useInView, useCountUp
- Brand colors and font: `src/index.css` (`@theme`)
